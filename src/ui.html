About & resources

Open Source - Map Generator stands on the shoulders of these projects. Click any name for the source.

  • MapLibre GL JS
    The mapping engine that renders every preview and export. BSD-3-Clause license.
  • CARTO basemaps
    Voyager / Light / Dark vector basemaps used by the default styles. Map tiles by CARTO, under CC BY 3.0.
  • OpenStreetMap
    Underlying map data for every basemap. © OpenStreetMap contributors, distributed under the Open Database License (ODbL).
  • Esri World Imagery
    Tiles for the Satellite style. Imagery © Esri, Maxar, Earthstar Geographics, USDA FSA, USGS, Aerogrid, IGN, IGP, UPR-EGP, and the GIS User Community.
  • OpenTopoMap
    Tiles for the Terrain style. Map style © OpenTopoMap (CC BY-SA 3.0); data © OpenStreetMap contributors and SRTM.

    Important: CC BY-SA is a "share-alike" licence. If you publish a design that includes a Terrain export, the published work inherits CC BY-SA 3.0 and must credit both OpenTopoMap and OpenStreetMap contributors. The Voyager / Light / Dark / Satellite styles do not have this constraint — they only require credit.
  • Nominatim
    Search powered by Nominatim, operated by the OpenStreetMap Foundation. Subject to the Nominatim Usage Policy.
  • OpenRouteService
    Driving directions for the Roads route type. Operated by HeiGIT using OpenStreetMap data. Free tier (2,000 routes/day) requires a per-user API key — see the Routes tab for setup.

Per-basemap attribution is also shown live in the bottom-right of the map preview while you work.
